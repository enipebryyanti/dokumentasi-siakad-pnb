# Dokumentasi SIAKAD
 
## Deskripsi
Repository ini berisi dokumentasi Sistem Informasi Akademik (SIAKAD) untuk mengelola data mahasiswa, jadwal kuliah, KRS, dan nilai.
 
## Tujuan
Menyimpan dan mengelola dokumentasi sistem secara terpusat, terstruktur, dan mudah diakses menggunakan layanan cloud GitHub.
 
## Struktur Folder
- Proposal/ : dokumen proposal dan analisis kebutuhan
- Desain/ : desain sistem (ERD, DFD, mockup)
- Laporan/ : laporan pengembangan dan pengujian
 
## Pengguna Sistem
Mahasiswa, dosen, admin akademik, dan pimpinan.
